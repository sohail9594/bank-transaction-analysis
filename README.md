# bank-transaction-analysis
📊 Bank Transaction Analysis
📌 Overview

Analyzed banking transaction data to understand customer behavior, transaction trends, and identify anomalies.

🧰 Tools Used
 - SQL
 - Python
 - Tableau

🔍 Key Insights
 - Deposits exceed withdrawals indicating positive cash flow
 - Top customers contribute majority of transaction volume
 - Identified high-value transactions as potential anomalies
 - Observed trends in monthly transaction activity

📁 Files
bank_data_cleaned.csv → dataset
queries.sql → SQL analysis
Bank_project_dataset.ipynb → Python cleaning
